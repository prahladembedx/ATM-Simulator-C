# ATM-Simulator-C
A simple and secure console-based ATM application built using C. This program allows users to perform basic banking tasks like checking balance, depositing money, and withdrawing cash.

✨ Features
Secure Login: PIN-based authentication with 3 maximum attempts.

Balance Check: View current account balance instantly.

Deposits & Withdrawals: Easy-to-use menu for managing funds.

Input Protection: Built-in logic to handle invalid inputs safely.

Compile:
Bash
